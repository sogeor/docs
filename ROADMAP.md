# Roadmap

Horizon: through Q4 2027. Order follows the sogeor platform plan.

## Planned

- Site skeleton on GitHub Pages: MkDocs Material, strict build, link checks.
- Aggregation of `docs/` from platform repositories, pinned by tag and SHA, updated by Renovate.
- Cross-cutting pages: platform overview, principles, cluster constructor, network, security, compliance, capacity.
- Platform ADRs for every foundational decision.
- "Deploy everything" guide from an empty account to a working platform, completed as repositories are released.
- Runbooks (including incident response), threat models, postmortem and exercise templates.

## Not planned

- Documentation of a single repository written here instead of in that repository.
- Copies of regulatory texts (only references and mappings).
- Translations other than English.
- A versioned site per platform release (the site follows pinned repository versions).
