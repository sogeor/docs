# Configuration

Every option of this repository. Secrets are listed at the end.

## `sources.yaml`

Repositories whose `docs/` directory is aggregated into the site.

```yaml
repositories:
  - name: images
    title: Images
    url: https://github.com/sogeor/images
    ref: master
    sha: 40a8ff40c81694146a1524bcceff532f9d1848e7
```

| Key | Type | Default | Required | Description | Example |
|---|---|---|---|---|---|
| `repositories` | list | `[]` | yes | Aggregated repositories, in navigation order | — |
| `name` | string | — | yes | Directory name under `docs/repos/`; lowercase letters, digits, `.`, `_`, `-`; unique | `images` |
| `title` | string | — | yes | Section title under **Repositories** | `Images` |
| `url` | string | — | yes | `https://github.com/<owner>/<repo>`, no trailing slash or `.git` | `https://github.com/sogeor/images` |
| `ref` | string | — | yes | Tag or branch that `sha` belongs to; Renovate tracks it | `v1.0.0`, `master` |
| `sha` | string | — | yes | Full 40-character **commit** SHA that is built; for an annotated tag use the peeled `refs/tags/<tag>^{}` line of `git ls-remote` | `40a8ff…48e7` |

Validation errors stop the build with `error: sources.yaml: …`.

The aggregated repository must have `docs/`. Its `mkdocs.yml` `nav` is reused (paths prefixed with
`repos/<name>/`); without `nav`, only `docs/index.md` is linked.

## `mkdocs.yml`

Base site configuration. `tools/aggregate.py` writes `mkdocs.generated.yml`, which inherits it and adds the
**Repositories** section to `nav`.

| Key | Value | Notes |
|---|---|---|
| `site_url` | `https://docs.sogeor.com/` | Address of the published site; change it in a fork ([Custom domain](setup.md#custom-domain)) |
| `strict` | `true` | Any warning fails the build |
| `validation` | all `warn` | Broken links, unknown anchors, pages outside `nav` fail the strict build |
| `theme.features` | tabs, sections, indexes, code copy | No edit button: aggregated pages belong to other repositories |
| `markdown_extensions` | admonition, tables, superfences with Mermaid, tabbed, details | Same set as repository sites |
| `nav` | Home, Platform, Operations, Decisions, About | Every page must be listed |

## `tools/aggregate.py`

| Option | Default | Description |
|---|---|---|
| `--local NAME=PATH` | — | Use a local checkout for repository `NAME` instead of fetching `sha`; repeatable |
| `--offline` | off | Use cached checkouts in `.cache/sources/` only |

Generated paths (ignored by Git): `docs/repos/`, `mkdocs.generated.yml`, `.cache/`.
