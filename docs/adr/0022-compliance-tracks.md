# 0022 International and Russian compliance tracks

- Status: proposed
- Date: 2026-10-11

## Context and problem statement

The platform is a reference for both international employers and Russian regulated environments.

## Decision drivers

- Show mappings, not copies of regulations.
- Evidence generated by the platform itself.

## Considered options

1. Two tracks with a shared control matrix in the `compliance` repository
2. International only
3. Separate platforms per track

## Decision outcome

Chosen option: "Two tracks with a shared control matrix in the `compliance` repository".

- International: CIS, NSA/CISA, MITRE ATT&CK, NIST SSDF, SLSA, OWASP SAMM/ASVS.
- Russian: Astra pool, GOST R 56939-2024, FSTEC orders 17/21/239, BDU, integration points for domestic tools.

### Consequences

- Good: one platform, two audiences.
- Bad: mappings must be kept current with framework revisions.

## Pros and cons of the other options

### International only

- Bad: not applicable to Russian regulated environments.

### Separate platforms per track

- Bad: duplication.
