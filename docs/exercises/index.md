# Exercises

Planned tests of recovery and response: restore drills, chaos experiments and tabletop exercises. Each
follows the [exercise template](template.md) and starts with a hypothesis.

| Exercise | Type | Frequency | Status |
|---|---|---|---|
| Restore CloudNativePG and Velero backups into a new cluster | restore drill | monthly | planned |
| Lose `mgmt`: recover from Git and backups | DR drill | yearly | planned |
| Kill a workload node | chaos (Chaos Mesh) | quarterly | planned |
| Leaked CI credential | tabletop | yearly | planned |
| Unseal OpenBao with key holders | drill | yearly | planned |
